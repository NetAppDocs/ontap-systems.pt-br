= Analise os requisitos para a substituição de um chassi em um sistema FAS9000
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de substituir o chassi em um sistema FAS9000, verifique se todos os outros componentes estão funcionando corretamente e se o chassi de substituição é do mesmo modelo que o chassi com problema. O procedimento é disruptivo, causando uma interrupção completa em um cluster de dois nós ou uma interrupção parcial em um cluster com vários nós.

Todos os outros componentes do sistema devem estar funcionando corretamente; caso contrário, você deve entrar em Contato com o suporte técnico.

* Pode utilizar este procedimento com todas as versões do ONTAP suportadas pelo seu sistema.
* Este procedimento é disruptivo. Para um cluster de dois nós, você terá uma interrupção de serviço completa e uma interrupção parcial em um cluster de vários nós.
