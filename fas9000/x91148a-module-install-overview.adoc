= Saiba como adicionar módulos X91148A a um sistema de storage FAS9000
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Adicione um módulo X91148A a um FAS9000 substituindo uma placa de rede ou um adaptador de armazenamento por um novo em um sistema totalmente equipado, ou adicionando uma nova placa de rede ou um adaptador de armazenamento em um slot vazio do chassi.

Você pode adicionar um módulo de e/S ao sistema substituindo uma NIC ou um adaptador de armazenamento por um novo em um sistema totalmente preenchido ou adicionando uma nova NIC ou adaptador de armazenamento em um slot de chassi vazio no sistema.

.Antes de começar
* Verifique o  https://hwu.netapp.com["NetApp Hardware Universe"] para garantir que o novo módulo de E/S é compatível com o seu sistema e com a versão do ONTAP que você está utilizando.
* Se houver vários slots disponíveis, verifique as prioridades dos slots em  https://hwu.netapp.com["NetApp Hardware Universe"] e use o melhor disponível para o seu módulo de E/S.
* Para adicionar um módulo de e/S sem interrupções, você deve adquirir o controlador de destino, remover a tampa cega do slot no slot de destino ou remover um módulo de e/S existente, adicionar o módulo de e/S novo ou de substituição e, em seguida, giveback o controlador de destino.
* Certifique-se de que todos os outros componentes estão a funcionar corretamente.
