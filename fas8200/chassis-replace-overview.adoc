= Analise os requisitos antes de substituir o chassi em um sistema FAS8200
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de substituir o chassi em um sistema FAS8200, verifique se todos os outros componentes estão funcionando corretamente e se o chassi de substituição é um componente novo da NetApp do mesmo modelo. O procedimento requer mover as fontes de alimentação, ventoinhas e módulos controladores para o novo chassi e é disruptivo, causando uma interrupção completa em um cluster com dois controladores ou uma interrupção parcial em um cluster com vários nós.

Todos os outros componentes do sistema devem estar funcionando corretamente. Caso contrário, entre em contato com o suporte técnico.

* Pode utilizar este procedimento com todas as versões do ONTAP suportadas pelo seu sistema.
* Este procedimento é escrito com a suposição de que você está movendo o módulo do controlador ou os módulos para o novo chassi e que o chassi é um novo componente do NetApp.
* Este procedimento é disruptivo. Em um cluster com dois controladores, você terá uma interrupção completa do serviço e, em um cluster com vários nós, uma interrupção parcial.
