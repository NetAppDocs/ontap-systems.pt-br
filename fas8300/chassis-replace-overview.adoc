= Analise os requisitos antes de substituir o chassi em um sistema FAS8300 ou FAS8700
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de substituir o chassi do seu FAS8300 ou FAS8700, todos os outros componentes do sistema devem estar funcionando corretamente; caso contrário, você deve entrar em contato com o suporte técnico. Este procedimento é compatível com todas as versões do ONTAP, mas causa uma interrupção completa em um cluster de dois controladores e uma interrupção parcial em um cluster com vários nós.

* Pode utilizar este procedimento com todas as versões do ONTAP suportadas pelo seu sistema.
* Este procedimento é disruptivo: um cluster com dois controladores sofre uma interrupção completa de serviço, e um cluster com vários nós sofre uma interrupção parcial.
