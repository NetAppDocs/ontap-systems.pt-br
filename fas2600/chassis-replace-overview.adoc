= Analise os requisitos para a substituição de um chassi em um sistema FAS2600
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de substituir o chassi do seu sistema FAS2600, revise os requisitos para mover as fontes de alimentação, discos rígidos e módulo ou módulos controladores do chassi com problema para o novo chassi, e trocar o chassi com problema no rack de equipamentos ou gabinete do sistema pelo novo do mesmo modelo.

Todos os outros componentes do sistema devem estar funcionando corretamente. Caso contrário, entre em contato com o suporte técnico.

* Pode utilizar este procedimento com todas as versões do ONTAP suportadas pelo seu sistema.
* Este procedimento é escrito com a suposição de que você está movendo todas as unidades e módulos de controladora ou módulos para o novo chassi e que o chassi é um novo componente da NetApp.
* Este procedimento é disruptivo. Para um cluster de dois nós, você terá uma interrupção completa do serviço e, para um cluster de vários nós, você terá uma interrupção parcial.
