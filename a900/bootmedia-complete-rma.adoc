= Devolva a mídia de inicialização com falha do AFF A900 para a NetApp após o processo de recuperação de inicialização manual
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se um componente no seu sistema AFF A900 falhar, devolva a peça com falha para a NetApp. Consulte a  https://mysupport.netapp.com/site/info/rma["Devolução de peças e substituições"] página para mais informações.

Devolva a peça com falha ao NetApp, conforme descrito nas instruções de RMA fornecidas com o kit. Consulte a https://mysupport.netapp.com/site/info/rma["Devolução de peças e substituições"] página para obter mais informações.
