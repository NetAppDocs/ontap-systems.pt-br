= Fluxo de trabalho de substituição do chassi AFF A400
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Comece a substituir o chassi do seu AFF A400 desligando os controladores, transferindo o hardware para o chassi de substituição e concluindo a restauração do sistema.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"]link:chassis-replace-shutdown.html["Desligue os controladores"]
[role="quick-margin-para"]
Desligue os controladores para realizar a manutenção do chassi com segurança.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dois"]link:chassis-replace-move-hardware.html["Substitua o chassis"]
[role="quick-margin-para"]
Transfira as ventoinhas, as unidades de disco e os módulos de controle do chassi com problema para o chassi de substituição.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Três"]link:chassis-replace-complete-system-restore-rma.html["Complete a substituição do chassis"]
[role="quick-margin-para"]
Conclua a substituição verificando o estado de HA, revertendo os agregados, se necessário, e devolvendo o chassi com falha para a NetApp.
