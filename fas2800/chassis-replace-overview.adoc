= Analise os requisitos antes de substituir o chassi em um sistema FAS2820
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para substituir o chassi do seu FAS2820, transfira as fontes de alimentação, os discos rígidos e os módulos controladores do chassi com problema para o novo chassi. Em seguida, remova o chassi com problema do rack de equipamentos ou do gabinete do sistema e instale o novo chassi do mesmo modelo no lugar dele.

Todos os outros componentes do sistema devem estar funcionando corretamente. Caso contrário, entre em contato com o suporte técnico.

* Pode utilizar este procedimento com todas as versões do ONTAP suportadas pelo seu sistema.
* Este procedimento é escrito com a suposição de que você está movendo todas as unidades e módulos de controladora ou módulos para o novo chassi e que o chassi é um novo componente da NetApp.
* Este procedimento é disruptivo. Para um cluster com dois controladores, este procedimento causa uma interrupção completa do serviço e uma interrupção parcial em um cluster com vários nós.
