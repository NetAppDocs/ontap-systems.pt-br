= Devolva a mídia de inicialização FAS2820 com falha para a NetApp após o processo de recuperação manual de inicialização
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após substituir a mídia de inicialização no seu FAS2820, devolva a peça com defeito para NetApp, conforme descrito nas instruções de RMA fornecidas com o kit.

Devolva a peça com falha ao NetApp, conforme descrito nas instruções de RMA fornecidas com o kit. Consulte a https://mysupport.netapp.com/site/info/rma["Devolução de peças e substituições"] página para obter mais informações.
