= Devolva a mídia de inicialização FAS2700 com falha para NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após substituir a mídia de inicialização do seu sistema FAS2700, devolva a peça com falha para NetApp, conforme descrito nas instruções de RMA fornecidas com o kit.

Consulte a página  https://mysupport.netapp.com/site/info/rma["Devolução de peças e substituições"] para obter mais informações. O sistema FAS2700 suporta apenas procedimentos manuais de recuperação da mídia de inicialização. A recuperação automática da mídia de inicialização não é suportada.
