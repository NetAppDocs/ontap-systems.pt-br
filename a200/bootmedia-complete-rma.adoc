= Devolva a mídia de inicialização AFF A200 com falha para NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Devolva a mídia de inicialização com defeito do AFF A200 para a NetApp após substituir a mídia de inicialização, conforme descrito nas instruções de RMA fornecidas com o kit. Consulte a página  https://mysupport.netapp.com/site/info/rma["Devolução de peças e substituições"] para obter mais informações.
