= Devolva a mídia de inicialização com falha do AFF A800 para a NetApp após o processo de recuperação de inicialização manual
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após concluir o processo de recuperação manual de inicialização para uma mídia de inicialização com falha em seu AFF A800, devolva a peça com defeito para NetApp. Consulte a https://mysupport.netapp.com/site/info/rma["Devolução de peças e substituições"] página para obter detalhes.
