= Devolva a mídia de inicialização com falha da AFF A800 para a NetApp após o processo de recuperação de inicialização automatizado
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após concluir o processo automatizado de recuperação de inicialização para uma mídia de inicialização com falha no seu AFF A800, devolva a peça com defeito para a NetApp. Consulte a página  https://mysupport.netapp.com/site/info/rma["Devolução de peças e substituições"] para obter detalhes.
