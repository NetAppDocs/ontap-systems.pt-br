= Analise os requisitos antes de substituir o chassi em um sistema FAS9500
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para substituir o chassis, tem de remover as fontes de alimentação, as ventoinhas, os módulos do controlador, os módulos de e/S, os módulos DCPM e o módulo LED USB do chassis danificado, remover o chassis danificado do rack do equipamento ou do armário do sistema, instalar o chassis de substituição no respetivo lugar e, em seguida, instalar os componentes no chassis de substituição.

.Antes de começar
Todos os outros componentes do sistema devem estar funcionando corretamente; caso contrário, entre em contato com o suporte técnico.

.Sobre esta tarefa
* Pode utilizar este procedimento com todas as versões do ONTAP suportadas pelo seu sistema.
* Este procedimento é disruptivo. Para um cluster de dois nós, você terá uma interrupção completa do serviço e, em um cluster com vários nós, uma interrupção parcial.
