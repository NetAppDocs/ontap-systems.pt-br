= Devolva a mídia de inicialização com falha da AFF C250 para a NetApp após o processo de recuperação de inicialização automatizado
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após substituir a mídia de inicialização em um AFF C250, devolva a peça com defeito para NetApp, conforme descrito nas instruções de RMA fornecidas com o kit. Consulte a  https://mysupport.netapp.com/site/info/rma["Devolução de peças e substituições"] página para obter mais informações.
